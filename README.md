# Brijesh Yadav | Portfolio Website

A personal portfolio website built with plain **HTML, CSS and vanilla JavaScript** in a single file. No frameworks, no build step, no dependencies.

**Live site:** https://brijesh-rgb.github.io/Brijesh-Yadav/

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in any modern browser.

```bash
git clone https://github.com/brijesh-rgb/Brijesh-Yadav.git
cd Brijesh-Yadav
# then open index.html in your browser
```

## Deploy to GitHub Pages

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Select the **main** branch and the **/ (root)** folder, then click **Save**.
4. Wait a minute or two, then open the published URL.

## Customize

All personal details are marked with `EDIT:` comments in `index.html`. Search for `EDIT:` to update your email, links and project repositories. The color theme is defined by the `--brand`, `--brand-2` and `--accent` variables at the top of the `<style>` block.
